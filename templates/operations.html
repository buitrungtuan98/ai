Two interventions, no SSH. Neither can touch a render that is genuinely progressing.

Fails episodes that are definitively dead and releases a render lock left by a crashed worker — now, instead of at the next hourly housekeeping tick. Use this when an episode is frozen mid-render.

Asks the worker to exit; its container is recreated automatically. Takes about a minute. A worker frozen so hard that even its own threads cannot run is the one case this cannot reach — that needs the box itself.

How a frozen render heals itself

Rendering is one long job, so “stuck” has to be defined by time. Three layers, deliberately ordered from gentlest to bluntest:

  1. RQ job timeout — a render running longer than its hard cap is failed cleanly, and the queue moves on.
  2. Watchdog ({{ w.stall_limit_min }} min without progress) — a render that outlived even that cap has a worker that stopped executing, so the episode is failed and the worker restarts itself. Slow-but-alive renders never reach here: image generation, stitching and Auto-QC each report no progress for minutes at a time, which is normal.
  3. Housekeeping tick — anything still stranded is failed so Retry works. The Recover button above is this same sweep, on demand.
