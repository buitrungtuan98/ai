Shared by the "Add a Facebook Page" form and each Page's "Replace token" panel, so the instructions cannot drift apart. #}
How do I get a permanent Page Access Token?
  1. Open the Graph API Explorer and pick (or create) an app.
  2. In the User or Page dropdown choose your Page — not “User token”. This is the step that decides everything: a user token reads your Page’s name fine, so it looks right, but it cannot post and it expires within hours.
  3. Add the permissions pages_manage_posts, pages_read_engagement and pages_show_list, then Generate Access Token.
  4. Paste it into the Access Token Debugger and press Extend Access Token — the extended Page token has Expires: Never. That is the one to paste here.

Your Page ID is on the Page under About → Page transparency; you can also just paste the Page’s URL here and we’ll resolve it.
